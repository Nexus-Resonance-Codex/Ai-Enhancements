The determinant $\det(M(T_N)) = \det(\phi^N I_D) = (\phi^N)^D \neq 0$.
By the Invertible Matrix Theorem, $T_N$ is bijective and invertible, with inverse $T_N^{-1}(v) = \phi^{-N} v$.
Thus, \texttt{InfiniteEInfinityContextUnfolder} constitutes a continuous linear isomorphism with zero kernel nullity ($\ker(T_N) = \{0\}$).
\end{proof}
